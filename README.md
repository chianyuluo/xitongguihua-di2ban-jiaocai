# 软考系规（系统规划与管理师）第 2 版 · 备考 Skill

> 把《系统规划与管理师教程（第 2 版）》结构化提炼而成的 agent skill，供 WorkBuddy / Claude 等支持 skills 的 AI 助手调用，辅助软考系规备考（知识点梳理、案例找错、论文技法、考点速记）。

## 这是什么
- **不是教材原文，而是框架型提炼**：每章抽取 Core Idea / Frameworks / Key Concepts / Mental Models / Anti-patterns / Takeaways，便于快速取料与出题。
- 覆盖：24 章知识框架、**IT 服务四要素（人员/资源/技术/过程）**、服务管理 8 过程（级报事件问配变发安）、服务生命周期 5 阶段、数字中国"2522"、新一代信息技术 7 大领域、速记清单、术语表、案例反模式、论文写作技法。

## 目录结构
- `SKILL.md`：主索引（框架 / 原则 / 技法 / 反模式层）
- `chapters/ch01~ch24.md`：24 章结构化笔记
- `cheatsheet.md`：口诀 / 阶段归属 / 决策规则速查
- `glossary.md`：核心术语
- `patterns.md`：案例找错反模式 / 论文技法 / 规划方法选型套路
