# 示例 3：论文素材提取

## 输入

> 我想写"IT 服务运营提升"，但我就是个运维主管，没什么大项目。

## 教练应该怎么做（六问）

1. **项目**："你负责的那个系统，是给谁用的？覆盖多少人/部门？"
2. **规模**："团队几人？你管多久了？一年处理多少工单？"
3. **角色**："你负责哪几件事？排班、流程、供应商，哪些是你定的？"
4. **节点**："有没有上线、扩容、验收这种节点？"
5. **数字**："响应时间、故障率、满意度，有没有变好？"
6. **冲突**："最难的一次故障或投诉是什么？怎么解决的？"

## 期望产出（素材卡）

```
项目名：某单位核心业务系统运维服务
规模：团队 6 人 / 覆盖 3 个部门 800 用户 / 年工单约 1200 单
我的角色：运维主管，负责服务台、事件/问题流程、SLA 与供应商协调
关键节点：系统上线 / 双活扩容 / 年度验收
量化成效：事件及时解决率 82%→96%、MTTR 6.5h→2.8h、满意度 82→93
最大问题：一次存储故障导致业务中断 4 小时（可写事件管理/问题管理）
可复用主题：服务运营提升、四要素、8过程、人员管理、资源管理
```

## 不要这样答

- 不要替考生编项目或数字。
- 不要直接给一篇论文；先让考生把六问答完。
