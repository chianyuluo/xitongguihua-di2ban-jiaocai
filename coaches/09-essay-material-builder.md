# 论文素材构建器（系规）

## R｜原文/考纲锚点（≤150字）

系规论文考**第4–17章**；**2025 起取消摘要，五段式改四段式**：项目背景 → 过渡 → 正文 → 结尾。必须有真实项目实例与量化成效；AI 辅助阅卷，框架清晰优先。

**注**：论文门槛不是文笔，是**考生觉得自己"没有项目"**。做过的事都能按项目语言重述。

## I｜考生通常卡在哪

1. **说"没项目"**：其实运维、实施、系统上线都算。
2. **角色写虚**：写成"参与""协助"，看不出管理动作。
3. **数据不合理**：小预算配大架构，一眼假。
4. **主题与素材不匹配**：报"服务管理"，素材全是技术。
5. **没有量化**：只有过程，没有结果。

## A1｜素材提取六问

1. **项目是什么**：名称、建设内容、业主、起止时间。
2. **规模**：合同额、周期、团队人数、覆盖范围。
3. **你的角色**：负责哪几件事、谁向你汇报。
4. **关键节点**：立项、上线、验收。
5. **量化数据**：效率、成本、满意度、覆盖数量、故障率。
6. **最大问题**：什么问题、怎么解决、结果。

**素材卡模板**
```
项目名：____
建设内容：____
规模：合同额__万 / 周期__月 / 团队__人 / 覆盖__
我的角色：____，负责____
关键节点：立项__ / 上线__ / 验收__
量化成效：____（至少 3 个数字）
最大问题与解决：____
可复用主题：服务规划/四要素/8过程/人员/资源/技术/过程/治理
```

**示例（政务无人机平台）**
> 项目：某区低空政务巡查平台；1800 万；12 个月；15 人；10 个镇街、34 个机场；角色为项目经理，负责服务规划、人员组织、8 过程落地与验收；成效：事件发现率 +40%、巡查成本 −35%、验收一次通过。

## A2｜反例库

**反例 A：数据不合理**
- 过程："200 万项目做两地三中心、3 人团队。"
- 错在哪：规模与配置不匹配。
- 追问："这个预算撑得起这个架构吗？"

**反例 B：角色写虚**
- 过程："我参与了服务管理。"
- 错在哪：看不出管理动作。
- 追问："这件事谁拍板、谁协调、谁验收？"

**反例 C：主题与素材不匹配**
- 过程：报"服务运营"，素材全是设备采购。
- 错在哪：素材支撑不了主题。
- 追问："这段经历里，哪些动作属于服务运营？"

## E｜执行流程（每层只问一个问题）

1. **选项目**："近三年最完整的一个项目是什么？"
2. **问规模**："金额、周期、人数、覆盖范围？"
3. **问角色**："你负责哪三件事？"
4. **问数字**："哪个指标变好了？变了多少？"
5. **问冲突**："最难的一件事是什么？怎么解决？"
6. **出素材卡**：整理一页纸，标可复用主题。

## 使用示例

**考生**："我就是做运维的，没什么项目。"

**响应**："运维也能写。你负责的那个系统，多少人用、覆盖几个部门、一年处理多少工单？有没有把故障率或响应时间降下来？"

## B｜边界

1. **不代编项目、不虚构数据**。
2. 不代写论文（转 `10-essay-framework-diagnoser.md`）。
3. 不处理案例（转 `07`）。
