# 服务 8 过程教练

## R｜原文/考纲锚点（≤150字）

服务管理 8 过程口诀：**"级报事件问配变发安"**——级别管理、服务报告、事件管理、问题管理、配置管理、变更管理、发布管理、安全管理。第12章是系规绝对核心（综合约22–23题），案例与论文主线。

**注**：案例找错时，8 过程就是**检查清单**；漏一个过程，就少一个得分点。

## I｜考生通常卡在哪

1. **口诀背不全**：只记得"事件、问题、变更"。
2. **事件 vs 问题**：事件是恢复服务（要快），问题是找根因（防复发）。
3. **变更 vs 发布**：变更管审批（CCB），发布管上线；必须分离。
4. **配置管理缺失**：没有 CMDB，配置项不受控。
5. **服务报告/级别管理被忽略**：没有 SLA、没有月度报告。

## A1｜8 过程逐项表

| 过程 | 目标 | 关键活动 | 高频找错点 |
|---|---|---|---|
| 级别管理 | 定义服务级别并签 SLA | 识别需求、定制 SLA、监控达成 | 无 SLA / 无量化指标 |
| 服务报告 | 定期输出服务报告 | 计划、编制、分发、归档 | 无报告机制 |
| 事件管理 | 尽快恢复服务 | 侦测、记录、分级、分派、解决、关闭 | 无升级机制 / 事件=问题 |
| 问题管理 | 找根因、防复发 | 识别、根因分析、已知错误库、关闭 | 只救火不分析 |
| 配置管理 | 管 CMDB 与基线 | 配置项识别、建库、审计、基线 | 无 CMDB / 未受控 |
| 变更管理 | 管控变更请求 | 提出、评估、CCB 审批、实施、回顾 | 未审批 / 变更=发布 |
| 发布管理 | 安全上线到生产 | 计划、构建、测试、部署、回退 | 无回退方案 |
| 安全管理 | 全周期安全保密 | 风险、策略、访问控制、审计 | 安全游离于过程外 |

**案例扫描**：按口诀顺序，逐个问"材料里有没有这个过程的动作？缺了就记一条"。

## A2｜反例库

**反例 A：事件当问题**
- 过程："同类故障反复，说明事件管理没做好。"
- 错在哪：反复发生是"没找根因"，属问题管理。
- 追问："恢复服务是哪个过程？找根因、防复发是哪个过程？"

**反例 B：变更当发布**
- 过程："版本上线没审批，是发布管理的问题。"
- 错在哪：没审批是变更管理（CCB）；发布管理管上线动作与回退。
- 追问："'批不批'归哪个过程？'上不上线'归哪个过程？"

**反例 C：漏配置管理**
- 过程：材料说"配置散落在个人电脑"，考生只写"文档管理不规范"。
- 错在哪：应落到配置管理 + CMDB + 配置审计。
- 追问："配置项由哪个过程管？它的库叫什么？"

## E｜执行流程（每层只问一个问题）

1. **背口诀**："8 过程按口诀说一遍。"
2. **逐项核对**："材料里，级别管理有动作吗？服务报告呢？……"
3. **定位漏项**："哪几个过程完全没提？"
4. **改正**："漏的这个过程，正确做法写一句。"

## 使用示例

**考生**："材料里事件处理挺快的，应该没问题。"

**响应**："事件快，说明恢复服务做到了。但同类故障反复出现，问题管理做了吗？根因分析、已知错误库有没有？"

2. 不覆盖四要素的整体框架（转 `02-siyaosu-framework-coach.md`）。
