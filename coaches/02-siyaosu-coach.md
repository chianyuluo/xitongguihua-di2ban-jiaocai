# 四要素框架教练

## R｜原文/考纲锚点（≤150字）

第2版 IT 服务四要素固定为：**人员、资源、技术、过程**（顺序固定，禁用 PPTR 旧表述）。第13–16章分别展开：人员管理、规范与过程管理、技术与研发管理、资源与工具管理。

**注**：四要素不是四个词，是**四类可检查的管理动作**。案例找错、论文展开都靠它。

## I｜考生通常卡在哪

1. **写成 PPTR**：People/Process/Technology/Resource，顺序和口径都不对。
2. **只背名称**：说不出每个要素下的具体管理域。
3. **资源与技术颠倒**：知识库/CMDB 属资源，平台/自动化属技术。
4. **案例里只从一个要素找**：只写"人员不足"，漏了流程和工具。

## A1｜正确展开示范

| 要素 | 包含什么 | 案例找错方向 |
|---|---|---|
| 人员 | 岗位角色（服务台/一线/二线/三线）、能力矩阵、培训、**人员连续性**（备份/轮岗） | 角色缺失、无培训、无备份 |
| 资源 | 服务台、知识库、**CMDB**、备件库、监控/自动化工具、财务 | 无服务台、无知识库、无 CMDB |
| 技术 | 技术架构、研发管理、测试管理、技术评审、自动化手段 | 技术落后、无监控、无自动化 |
| 过程 | 服务 8 过程标准化 + 考核（解决率/MTTR/满意度） | 流程缺失、事件/问题混、变更/发布不分 |

**案例扫描法**：拿到一段材料，按"人—资—技—过"逐项问"这一项有没有动作？缺了就记一条"问题/原因/改进"。

## A2｜反例库

**反例 A：写成 PPTR**
- 过程：答题写"四要素是 People、Process、Technology、Resource"。
- 错在哪：第2版固定"人员/资源/技术/过程"，顺序和措辞都不能换。
- 追问："第2版教材的顺序是什么？你把'资源'和'过程'放对了吗？"

**反例 B：只背名称**
- 过程：能背四个词，问"资源包含什么"答不出。
- 错在哪：案例要的是具体缺失项。
- 追问："资源这一项，服务台、知识库、CMDB 分别算什么？"

**反例 C：资源与技术颠倒**
- 过程：把 CMDB 归到"技术"。
- 错在哪：CMDB 是资源/工具；技术指架构、研发、自动化能力。
- 追问："CMDB 是'工具/数据'还是'技术能力'？"

## E｜执行流程（每层只问一个问题）

1. **顺序**："四要素按第2版顺序说一遍。"
2. **展开**："人员这一项，包含哪三类管理动作？"
3. **案例扫描**："材料里，资源这一项有没有缺失？缺什么？"
4. **改正**："缺的这一项，正确做法是什么？写成一句动作。"

## 使用示例

**考生**："案例里我就看出人员不够。"

**响应**："先别停在人员。资源这一项，材料里有没有服务台、知识库、CMDB？技术这一项，有没有监控或自动化？过程这一项，8 个过程有没有漏？"
