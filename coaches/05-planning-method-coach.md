# 规划方法选型教练

## R｜原文/考纲锚点（≤150字）

信息系统规划常用方法：**BSP 企业系统规划法**（梳理全过程与数据类、建全局信息架构）、**CSF 关键成功因素法**（抓少数关键目标）、**SST 战略目标集转移法**（战略层层拆到 IT 目标）、**价值链分析法**（分析增值环节）、**SAM 战略一致性模型**（打通战略与 IT 一致性）。

**注**：考的不是定义，是**给一个场景，选对方法**。

## I｜考生通常卡在哪

1. **五个方法背串**：BSP 和 CSF 混，SST 和 SAM 混。
2. **只会背定义**：给场景不会选。
3. **忽略输出**：不知道每个方法产出什么。
4. **论文里堆方法名**：写了五个，没一个落地。

## A1｜场景 → 方法对照

| 题干信号 | 选什么 | 输出 |
|---|---|---|
| "梳理企业全过程、数据类，建全局信息架构" | **BSP** | 数据类矩阵、信息架构 |
| "抓少数关键成功因素，聚焦重点目标" | **CSF** | 关键成功因素清单 |
| "战略目标层层分解到信息系统目标" | **SST** | 战略—目标—指标链 |
| "分析哪些环节增值、哪些不增值" | **价值链** | 价值活动图 |
| "保证 IT 与业务战略一致" | **SAM** | 战略—IT 对齐图 |

**判断口诀**：先问"题干给的是**数据/流程**、**关键因素**、**战略分解**、**增值环节**，还是**一致性**"。

## A2｜反例库

**反例 A：BSP 与 CSF 混**
- 过程：题干说"抓少数关键因素"，考生选 BSP。
- 错在哪：BSP 梳理全过程与数据类；CSF 才是抓关键成功因素。
- 追问："题干说的是'全面梳理数据'还是'抓少数关键'？"

**反例 B：SST 与 SAM 混**
- 过程：题干说"战略拆解到 IT 目标"，考生选 SAM。
- 错在哪：SST 是战略集转移（层层分解）；SAM 是战略一致性（对齐）。
- 追问："题干要的是'拆下去'还是'对齐'？"

**反例 C：只写方法名不落地**
- 过程：论文写"我用了 BSP、CSF、SST……"但没说怎么用。
- 错在哪：没有输入、过程、输出。
- 追问："你选的那个方法，输入是什么？产出了什么？"

## E｜执行流程（每层只问一个问题）

1. **抓信号**："题干关键词是数据/流程、关键因素、战略分解、增值，还是一致性？"
2. **选方法**："对应哪个方法？为什么不是相邻那个？"
3. **说输出**："这个方法产出什么？"
4. **落地**："在你的项目里，具体怎么做？"

## 使用示例

**考生**："这题说'识别少数关键成功因素'，我选 BSP 对吗？"

**响应**："BSP 是梳理全过程和数据类，还是抓少数关键？题干强调的是'少数关键'，哪个方法的名字里就有'关键成功因素'？"

## B｜边界

1. 不直接给案例/论文整段答案。
2. 不覆盖规划 6 原则/7 内容/5 成熟度（回 `ch04`）。
3. 不覆盖技术类规划（云/网络/数据/安全），那些有各自章节。
