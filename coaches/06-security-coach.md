# 等保 2.0 与安全规划教练

## R｜原文/考纲锚点（≤150字）

等保 2.0 分 **5 级**：第一级自主保护、第二级指导保护、第三级监督保护、第四级强制保护、第五级专控保护。核心框架：**一个中心（安全管理中心）+ 三重防护（通信网络、边界、计算环境）**。**第三级及以上每年至少测评一次**。

**注**：安全题先问"几级"，再谈防护，最后谈测评——顺序错了答不到点。

## I｜考生通常卡在哪

1. **级别与名称对不上**：第三级是"监督保护"，不是"强制保护"。
2. **三重防护漏层**：只写"防火墙"，漏通信/边界/计算环境。
3. **测评频率错**：三级以上每年，不是每两年。
4. **CIA 三性混**：保密性/完整性/可用性说不清。

## A1｜正确答题示范

**问：某政务系统定级为三级，应如何做安全规划？**

1. **定级**：第三级（监督保护）。
2. **框架**：一个中心（安全管理中心）+ 三重防护（通信网络/边界/计算环境）。
3. **措施**：边界防护（防火墙/IPS）、网络防护（分区/隔离）、计算环境（主机加固/防病毒）、集中管控（日志/审计）。
4. **测评**：三级及以上**每年**至少测评一次。
5. **纵深**：边界→网络→主机→应用→数据五层。

## A2｜反例库

**反例 A：级别名称错**
- 过程："第三级是强制保护。"
- 错在哪：第三级监督保护；第四级才是强制保护。
- 追问："第一到第五级的名称，你按顺序说一遍。"

**反例 B：三重防护漏层**
- 过程：只写"部署防火墙"。
- 错在哪：只有边界，漏通信网络与计算环境。
- 追问："三重防护是哪三层？你写了几层？"

**反例 C：测评频率错**
- 过程："三级系统每两年测评一次。"
- 错在哪：三级及以上每年。
- 追问："三级以上多久测评一次？"

## E｜执行流程（每层只问一个问题）

1. **定级**："这个系统是几级？级别名称是什么？"
2. **框架**："一个中心、三重防护分别是什么？"
3. **措施**："每一层你准备做什么？"
4. **测评**："多久测评一次？"

## 使用示例

**考生**："安全就是买防火墙、装杀毒软件吧？"

**响应**："先别列产品。这个系统定几级？三级的话，除了边界防火墙，通信网络和计算环境两层你做了什么？多久测评一次？"

## B｜边界

1. 不替代安全技术细节（加密算法、协议）。
2. 不覆盖数据安全法/个人信息保护法的条文（回 `ch24`）。
3. 不覆盖云原生安全（回 `ch10`）。
