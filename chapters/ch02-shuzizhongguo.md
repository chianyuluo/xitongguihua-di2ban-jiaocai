# Chapter 2: 数字中国与数智化发展

## Core Idea
本章把"信息化"上升到国家战略层：数字中国整体框架与数智化转型路径。核心是理解"2522"布局、数据要素化、数字基础设施，以及数智化（数字化+智能化）如何重塑组织能力。

## Frameworks Introduced
- **数字中国"2522"整体布局**：2 大基础（数字基础设施体系、数据资源体系）、5 条主线（数字经济、数字政务、数字文化、数字社会、数字生态文明）、2 大能力（数字治理能力、数字安全屏障）、2 个环境（数字化发展基础环境、数字化发展国内国际环境）。
- **数据要素市场化**：数据作为新型生产要素，沿"确权—流通—收益分配"配置，是数字经济的纽带。
- **数智化转型**：数字化（业务在线、数据沉淀）与智能化（AI 决策、预测）双轮驱动，区别于单纯信息化。

## Key Concepts
- **数字基础设施（新基建）**：5G、数据中心、算力网络、工业互联网等底层承载。
- **数据资源体系**：数据采集、汇聚、治理、共享、开放的全生命周期体系。
- **数字经济**：以数据为核心要素、以数字技术为驱动的经济形态。
- **数字政务**：以数据打通提升政府治理与服务效能。
- **数字化转型**：利用数字技术重构业务模式与组织能力。

## Mental Models
- 谈"战略背景"时套"2522"：案例/论文开头先定位到数字中国框架，再落到本组织。
- 区分三词：信息化（流程电子化）→ 数字化（数据资产化）→ 数智化（数据+智能决策）。

## Anti-patterns
- 把"数字中国框架"记成"十四五"旧口径，漏掉"数据资源体系"这一基础。
- 混淆数字化与数智化，案例里把简单系统上线说成"智能化转型"。

## Key Takeaways
1. 数字中国"2522"是案例/论文必用的时代背景框架。
2. 数据要素化是贯穿第2版的主线（数据已成为生产要素）。
3. 数智化 = 数字化 + 智能化，是信息化的进阶。
4. 数字基础设施与数据资源体系是两大"基础"，优先投入。
