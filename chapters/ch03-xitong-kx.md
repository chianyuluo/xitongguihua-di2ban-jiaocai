# Chapter 3: 系统科学与哲学方法论

## Core Idea
本章给出做信息系统规划的"思想工具"：用系统科学的整体观和三大哲学方法论（矛盾论、实践论、系统论）来分析、设计复杂信息系统。考试重方法论的适用场景与选择。

## Frameworks Introduced
- **霍尔（Hall）三维结构（硬系统方法论）**：时间维（规划→设计→实施→运行）→逻辑维（明确问题→目标→方案→分析→决策→实施）→知识维（所需学科知识）。适用于目标清晰、结构良好的工程问题。
- **切克兰德（Checkland）软系统方法论**：适用于目标模糊、利益冲突的半结构化问题，用"概念模型"迭代比较，不追求唯一最优解。
- **三大哲学方法论**：①矛盾论——抓主要矛盾与矛盾的主要方面；②实践论——实践—认识—再实践—再认识的螺旋上升；③系统论——整体性、层次性、开放性、目的性、突变性、稳定性、自组织性等系统特性。
- **复杂系统方法论**：开放复杂巨系统需综合集成（定性定量结合）。

## Key Concepts
- **系统**：由相互作用的若干要素组成的、具有特定功能的有机整体。
- **整体性原理**：整体大于部分之和，是系统论第一原理。
- **层次性 / 开放性**：系统分层演进、与环境物质能量信息交换。
- **硬系统 vs 软系统**：问题结构是否清晰，决定用霍尔还是切克兰德。

## Mental Models
- 考题出现"干系人诉求冲突、目标不清"→ 选软系统方法论（切克兰德）。
- 考题出现"工期明确、方案可比"→ 选硬系统方法论（霍尔三维）。

## Anti-patterns
- 凡规划都套霍尔三维，忽略软系统对"非结构化问题"的适用性。
- 把矛盾论、实践论当成纯政治课内容，不落到"需求优先级排序/试点—推广"场景。

## Key Takeaways
1. 霍尔三维 = 时间×逻辑×知识，硬系统首选。
2. 切克兰德适合目标模糊的半结构化问题。
3. 矛盾论→抓重点；实践论→试点迭代；系统论→整体最优。
4. 系统特性（整体/层次/开放等）是选择题高频概念。
