# Chapter 16: 资源与工具管理

## Core Idea
资源与工具是四要素之"资源"：把知识库、工具平台、备件、资金等有形无形资源管好，让服务有"弹药"。本章聚焦资源的配置、共享与保值。

## Frameworks Introduced
- **资源分类**：知识资源（知识库）、工具资源（ITSM/监控/自动化平台）、硬件资源（备件/设备）、资金资源。
- **知识库管理**：采集→审核→结构化→检索→更新，避免知识随人流失。
- **工具链整合**：监控、告警、自动化的端到端联动，减少人工切换。
- **备件与资产管理**：资产台账、生命周期、冗余策略。

## Key Concepts
- **ITSM 平台**：事件/问题/变更/配置的统一工作台（过程要素的技术承载）。
- **可观测性工具**：日志/指标/链路追踪三位一体。
- **资源共享**：跨项目/客户复用资源，摊薄成本。
- **资源度量**：利用率、ROI，指导增配或回收。

## Mental Models
- 资源投入前先算利用率：闲置的工具=负债，重复的平台=浪费。
- 知识库是"人走知识留"的关键，制度上强制沉淀。

## Anti-patterns
- 工具买了一堆却没打通，告警靠人盯、数据靠手工导。
- 知识只在老员工脑子里，离职即断层。

## Key Takeaways
1. 资源四形态：知识/工具/硬件/资金。
2. 知识库要采集-审核-检索-更新闭环。
3. 工具链整合实现监控-告警-自动化联动。
4. 资源按利用率与 ROI 度量，回收闲置。
