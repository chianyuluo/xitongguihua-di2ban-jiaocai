# Chapter 22: 智能制造发展规划

## Core Idea
智能制造是制造业的数字化转型：以工业互联网为底座、以数据为纽带，实现设计—生产—供应链的柔性、协同与智能。规划重点是智能工厂架构与能力跃升。

## Frameworks Introduced
- **智能制造体系（参考智能制造能力成熟度模型 CMM）**：规划→生产→物流→销售→服务全价值链打通。
- **工业互联网架构**：网络（内网/外网）→平台（工业 PaaS）→安全→应用，标识解析体系。
- **智能工厂分层**：设备层→控制层→车间层→企业层→协同层。
- **C2M / 大规模定制**：从 MTS（按计划）到 C2M（按订单），反向拉动生产。

## Key Concepts
- **数字孪生工厂**：物理工厂的虚拟镜像，用于仿真优化。
- **柔性制造**：产线快速换型，适应多品种小批量。
- **标识解析**：工业品唯一身份，打通供应链数据。
- **预测性维护**：用数据预判设备故障，减少停机。

## Mental Models
- 智能制造不是"无人工厂"，而是"数据闭环+柔性"，先打通价值链再上 AI。
- 选 C2M 还是 MTS 看产品个性化程度与市场波动。

## Anti-patterns
- 重硬件自动化、轻数据打通，设备联网却无分析。
- 盲目上 AI 质检，数据质量与标注不足反而误判。

## Key Takeaways
1. 智能制造=工业互联网+数据+柔性+智能。
2. 能力成熟度贯穿规划到服务全价值链。
3. 数字孪生工厂用于仿真优化。
4. C2M 实现按需柔性生产。
5. 预测性维护降停机，标识解析通供应链。
