# Chapter 19: 智慧园区发展规划

## Core Idea
智慧园区是智慧城市在园区尺度的落地：以 IOC（智能运营中心）为枢纽，打通安防、能耗、停车、招商等场景，提升运营效率与体验。

## Frameworks Introduced
- **智慧园区总体架构**：终端感知→园区网络→园区平台（数字平台/IOC）→业务应用→运营服务。
- **IOC（智能运营中心）**：一屏统览、事件联动、指挥调度。
- **场景化规划**：先列场景清单（安防/门禁/能耗/会议/招商），按价值与可行性排序落地。
- **园区数字化转型成熟度**：信息化→数字化→智能化三级跳。

## Key Concepts
- **数字平台 / 园区中台**：统一接入设备与系统，避免孤岛。
- **AIoT**：AI + IoT，实现视频分析、异常预警。
- **绿色园区**：能耗监测与优化（双碳目标）。
- **产城融合**：园区与城市服务互通（交通/政务）。

## Mental Models
- 园区规划从"场景清单"出发：按"价值高×易落地"优先做，而非先买大平台。
- IOC 不是大屏，而是"事件能联动处置"的运营中枢。

## Anti-patterns
- 先建大屏 IOC，后补场景，结果空有展示无实效。
- 各系统独立建设，IOC 接不上数据。

## Key Takeaways
1. 园区架构：感知→网络→平台(IOC)→应用→运营。
2. IOC = 统览+联动+调度，重实效不重展示。
3. 场景化清单按价值×可行性排序落地。
4. AIoT 支撑安防与预警。
5. 绿色（双碳）是园区新动能。
