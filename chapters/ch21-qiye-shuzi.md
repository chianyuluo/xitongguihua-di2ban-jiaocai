# Chapter 21: 企业数字化转型发展规划

## Core Idea
企业数字化转型是组织级战略：用数字技术与数据重构业务模式、运营流程与组织能力，实现提质降本增效。规划核心是"战略—能力—场景"三层推进。

## Frameworks Introduced
- **数字化转型框架（战略→能力→场景）**：顶层战略定方向→核心能力（数据/技术/组织）建设→业务场景落地。
- **能力成熟度**：信息化→数字化→智能化→平台生态，逐级跃迁。
- **数据中台 / 业务中台**：沉淀共享能力，支撑前台敏捷创新。
- **转型路径**：顶层设计→试点验证→规模推广→持续优化。

## Key Concepts
- **数据驱动**：从经验决策转向数据决策。
- **业务重塑**：不只是流程上线，而是商业模式重构（如服务化、平台化）。
- **组织适配**：中台型/敏捷型组织替代科层烟囱。
- **数字化人才**：业务+数据+技术的复合能力。

## Mental Models
- 转型失败多在"只做系统不做能力、只做前台不做中台"，先夯数据中台再谈创新。
- 路径：小范围试点拿成效，再全面推广，别一刀切。

## Anti-patterns
- 把"上 ERP/上云"等同于数字化转型（只是信息化）。
- 缺数据中台，每个系统重复造轮子，数据不通。

## Key Takeaways
1. 转型三层次：战略→能力→场景。
2. 成熟度：信息化→数字化→智能化→平台生态。
3. 数据中台/业务中台是共享能力底座。
4. 路径：设计→试点→推广→优化。
5. 组织与人才须同步适配。
