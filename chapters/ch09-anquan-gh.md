# Chapter 9: 信息安全规划

## Core Idea
信息安全规划构建"技术+管理+运行"三维防护体系，落实等保2.0，做到纵深防御、数据安全和密码合规。第2版强化数据安全与关基保护。

## Frameworks Introduced
- **信息安全三维**：技术体系（防护产品）、管理体系（制度/组织/流程）、运行体系（监测/响应/演练）。
- **等保 2.0（网络安全等级保护）**：1–5 级，由低到高防护强度递增；"一个中心、三重防护"（安全管理中心 + 通信/边界/计算环境）。
- **纵深防御**：边界→网络→主机→应用→数据多层设防，单点失守不殃全局。
- **安全模型**：P2DR（策略 Policy+防护 Protect+检测 Detect+响应 Respond）、IATF 纵深。

## Key Concepts
- **数据安全**：分类分级、加密、脱敏、防泄漏（DLP）。
- **密码应用**：商用密码合规，传输/存储加密与签名。
- **零信任**：默认不信任、持续验证。
- **关键信息基础设施（关基）**：重点保护对象，需更高等级。

## Mental Models
- 安全规划按"先分级（等保定级）→ 再纵深（三层防护）→ 后运营（监测响应）"推进。
- 谈合规先问"等级"，不同级别决定投入强度。

## Anti-patterns
- 只堆安全设备（技术），忽视管理制度与应急演练（管理/运行）。
- 把等保当"买测评"，未真正落地三重重防。

## Key Takeaways
1. 安全是技术+管理+运行三维一体。
2. 等保2.0 三级防护+安全管理中心是硬性框架。
3. 纵深防御：边界/网络/主机/应用/数据层层设防。
4. 数据安全与密码合规是新增重点。
5. 关基需重点保护。
