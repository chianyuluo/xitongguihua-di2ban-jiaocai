# Chapter 8: 数据资源规划

## Core Idea
数据资源规划把"数据"作为核心资产来设计：建数据架构、做数据治理、定数据标准、管主数据，让数据可用、可信、可共享。第2版把数据要素化提到空前高度。

## Frameworks Introduced
- **数据架构分层**：ODS（操作数据层）→ DW（数据仓库）→ DM（数据集市），或贴源层→整合层→服务层。
- **数据治理框架**：数据标准、数据质量、元数据、主数据、数据安全、数据生命周期六大支柱（参照 DAMA 体系）。
- **主数据管理（MDM）**：对跨系统共享的"黄金记录"（客户/组织/物料等）统一源头、统一标识。
- **数据生命周期**：采集→存储→处理→共享→归档→销毁。

## Key Concepts
- **数据标准**：命名、编码、格式统一，是互通前提。
- **元数据**：描述数据的数据，分技术/业务/管理元数。
- **数据质量**：完整性、准确性、一致性、及时性、唯一性等维度。
- **数据湖 vs 数据仓库**：湖存原始多模数据，仓存主题化结构化数据。

## Mental Models
- 数据不通先查"主数据有没有统一源头"，再查"标准是否一致"。
- 数据治理不是买工具，先立标准与职责（数据Owner）。

## Anti-patterns
- 只建数仓不治理，结果"垃圾进垃圾出"，报表互相矛盾。
- 把元数据管理当文档归档，未纳入开发流程。

## Key Takeaways
1. 数据架构 ODS→DW→DM 分层清晰。
2. 数据治理六支柱（标准/质量/元数据/主数据/安全/生命周期）。
3. MDM 解决跨系统"同一对象多版本"问题。
4. 数据质量维度决定可信度。
5. 数据要素化是数字中国主线（Ch2）的落地抓手。
