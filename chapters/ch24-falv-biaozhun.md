# Chapter 24: 法律法规和标准规范

## Core Idea
本章是系规的合规底座：信息系统建设必须遵循网络安全、数据安全、个人信息保护等法规，并符合各类国家标准与行业标准。考试常以案例/论文的"合规红线"。

## Frameworks Introduced
- **法规层级**：法律（《网络安全法》《数据安全法》《个人信息保护法》）→行政法规（等保条例、关基保护条例）→部门规章→地方法规。
- **等保 2.0 合规**：系统定级→备案→建设整改→测评→监督检查（五步走）。
- **标准体系**：国家标准(GB/GB-T)、行业标准、地方标准、团体标准、企业标准（国标是底线）。
- **采购合规**：《政府采购法》《招标投标法》约束政府类信息系统项目。

## Key Concepts
- **网络安全法（CSL）**：网络运营者安全保护义务、关键信息基础设施保护。
- **数据安全法（DSL）**：数据分类分级、重要数据出境管理。
- **个人信息保护法（PIPL）**：告知-同意、最小必要、单独同意（敏感信息）。
- **标准作用**：统一接口/协议/评测，是互联互通与合规依据。

## Mental Models
- 案例出现"用户数据泄露/滥用"→ 立刻对标 PIPL（最小必要+告知同意）+ 等保。
- 政府项目先看采购/招标法，流程合规是硬约束。

## Anti-patterns
- 只做技术不问法，系统上线后才发现违反数据出境或个人信息规定。
- 把"标准"当建议，忽视国标是合规底线（如等保定级）。

## Key Takeaways
1. 三部核心法律：网安法/数据安全法/个人信息保护法。
2. 等保五步：定级→备案→建设→测评→监督。
3. 标准分级：国标底线、行标/团标/企标可选更高。
4. 政府项目遵政府采购法与招投标法。
5. 合规是规划与建设的"红线"，先法后术。
