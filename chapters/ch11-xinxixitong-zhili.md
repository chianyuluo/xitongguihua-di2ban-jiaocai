# Chapter 11: 信息系统治理

## Core Idea
信息系统治理解决"IT 投资是否对齐组织战略、决策权与问责是否清晰"。治理是"做正确的事"，管理是"正确地做事"——二者不同。

## Frameworks Introduced
- **治理三要素**：决策权分配、问责机制、流程与沟通。
- **COBIT 框架**：治理目标由企业目标级联（cascade）到 IT 目标，强调价值交付、风险管理、资源优化。
- **ISO/IEC 38500**：组织级 IT 治理的六原则（责任、战略、采购、性能、合规、人本）。
- **治理 vs 管理**：治理定方向/授权/监督；管理执行/运营。

## Key Concepts
- **IT 治理委员会**：由高层（通常 CIO/董事会层面）主导，确保 IT 与战略一致。
- **价值交付**：IT 投资回报与业务价值实现。
- **风险治理**：信息安全、合规、项目失败风险的对口职责。
- **IT 平衡计分卡**：从财务/客户/内部流程/学习成长评价 IT 绩效。

## Mental Models
- 考题问"谁对 IT 投资回报负责"→ 治理层（董事会/治理委），不是项目经理。
- 治理关注"做对的 IT"，管理关注"把 IT 做对"。

## Anti-patterns
- 把治理当成"加一套管理制度"，忽视决策权与问责的重新分配。
- 治理与管理混淆，治理委员会陷入日常运维决策。

## Key Takeaways
1. 治理=做正确的事（方向/问责），管理=正确地做事。
2. 治理三要素：决策权、问责、流程。
3. COBIT 用目标级联连接企业目标与 IT 目标。
4. ISO38500 六原则。
5. 治理由高层主导，对齐战略。
