# Chapter 15: 技术与研发管理

## Core Idea
技术与研发管理管的是四要素之"技术"和"研发过程"：如何让技术选型稳健、研发高效可控、成果可复用，并守住知识产权。

## Frameworks Introduced
- **研发过程模型**：瀑布（需求明确）、迭代/增量、敏捷（Scrum/Kanban，需求易变）、DevOps（开发运维一体）。
- **技术选型评估**：成熟度、适配性、成本、风险、生态五维度打分。
- **技术债务管理**：识别/量化/偿还，避免架构腐化。
- **知识产权管理**：专利、软著、商业秘密的分类保护与申报流程。

## Key Concepts
- **技术栈治理**：统一语言/框架，避免碎片化。
- **研发工具链**：需求→代码→构建→测试→部署的自动化流水线。
- **配置管理（代码）**：版本控制（Git）、分支策略。
- **新技术孵化**：试点→评估→推广的 gate 机制。

## Mental Models
- 需求易变选敏捷，需求冻结选瀑布；要快速反馈选 DevOps。
- 技术选型用五维度打分，别凭"新潮"拍脑袋。

## Anti-patterns
- 技术债务只借不还，系统越改越慢。
- 研发无工具链，靠人工串行，交付质量波动。

## Key Takeaways
1. 研发模型按需求稳定性选（瀑布/迭代/敏捷/DevOps）。
2. 技术选型五维度：成熟/适配/成本/风险/生态。
3. 技术债务要量化并持续偿还。
4. 知识产权（专利/软著/商业秘密）分类保护。
5. 工具链自动化是研发效率基石。
